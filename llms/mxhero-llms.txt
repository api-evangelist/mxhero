# mxHERO

> mxHERO Inc. is the pioneer of email-to-cloud content management. Its Mail2Cloud platform captures email and attachments (in-flight or at-rest) over SMTP/S and IMAP/S and routes them into cloud content platforms such as Box, Egnyte, Microsoft OneDrive, Google Drive, and Dropbox. Mail2Cloud Advanced adds an AI email knowledge layer with a Model Context Protocol (MCP) server for secure, agent-driven email search.

## APIs & Agent Surface
- [mxHERO Mail2Cloud Advanced](https://www.mxhero.com/advanced-ai): AI email knowledge recovery service with an official MCP server.
- [MCP server (Go)](https://github.com/mxaiorg/mxmcp): stdio MCP server exposing the `email_search` tool.
- [MCP server (Python)](https://github.com/mxaiorg/mxmcp-py): Python implementation of the same server.
- [Streamable HTTP endpoint](https://lab4-mcp.mxhero.com/mcp2/connect): hosted MCP transport.
- [Access tokens](https://lab4-mcp.mxhero.com/tokens): obtain mxHERO Vector Search credentials.
